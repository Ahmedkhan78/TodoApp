# Todo App with React and Tailwind CSS

This is a simple **Todo App** built using **React.js** and styled with **Tailwind CSS**. It includes a **Dark Mode toggle**, allowing users to switch between light and dark themes for better readability and customization.

## Features
- **Dark Mode**: Toggle between light and dark themes.
- **Add Todos**: Add new todos with descriptions.
- **Complete Todos**: Mark todos as completed.
- **Delete Todos**: Remove todos from the list.
- **Filter Todos**: Filter todos by status such as "All", "Completed", "Pending", and "High Priority".
- **Sort Todos**: Sort todos based on priority or due date.

## Technologies Used
- **React.js**: Frontend JavaScript framework for building the user interface.
- **Tailwind CSS**: Utility-first CSS framework for styling.
- **Local Storage**: Store todos persistently even after the page is reloaded.
- **Dark Mode**: Implemented a toggle feature to switch between light and dark themes.

## Installation

### 1. Clone the repository
```bash
git clone https://github.com/Ahmedkhan78/TodoApp.git
```

### 2. Install Dependencies
Navigate to the project directory and install the required dependencies:
```bash
cd TodoApp
npm install
```

### 3. Start the Development Server
Once the dependencies are installed, run the development server:
```bash
npm start
```

This will start the app at `http://localhost:3000`.

## Usage

### Dark Mode Toggle
Click the **"Switch to Dark Mode"** button to toggle between light and dark themes. The theme will persist even after a page reload, thanks to **localStorage**.

### Add a Todo
1. Enter your todo description in the input field.
2. Click the **"Add Todo"** button to add the todo to the list.
3. You can mark a todo as completed or delete it by clicking the respective buttons.

### Filter and Sort
Use the **Filter Dropdown** to view all, completed, pending, or high-priority todos. You can also **sort** todos by priority or due date.
